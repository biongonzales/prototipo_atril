Partitura

Toca una nota o un compás para elegir un tramo

Toca una nota o un compás para marcar el inicio del tramo, y toca otra para marcar el final. Un tercer toque empieza un tramo nuevo.

Tramo de práctica

Tramo Toda la pieza

Guía de uso

Primeros pasos
  1. Carga tu archivo. Pulsa «Cargar MIDI» o arrastra el archivo a la ventana. Sin archivo verás una pieza de ejemplo.
  2. Elige tu voz. Se selecciona el tenor por defecto; puedes cambiarla en «Voz a practicar».
  3. Marca el tramo que quieres ensayar. Toca una nota o un compás para el inicio y otra para el final.
  4. Reproduce. Con «Repetir tramo» activo, el fragmento se repite hasta que pulses «Detener».
Qué se escucha
Solo tu vozSolo la línea que estás practicando.
Tu voz + coroTu línea destacada con las demás voces de fondo.
Coro sin tu vozTodas las voces menos la tuya, para cantar encima.
OrquestaTodas las voces con un timbre más suave.
Ajustes de práctica
  • Tempo: baja la velocidad para aprender pasajes difíciles; verás el porcentaje respecto al original.
  • Cuenta: un compás de clics antes de empezar o en cada vuelta.
  • Metrónomo: clic durante toda la reproducción.
  • Atajo: la barra espaciadora reproduce y detiene.
Tus tramos guardados

Los tramos, el tempo y la voz elegida se guardan en tu cuenta para cada archivo. Si cambias el nombre del archivo MIDI, se tratará como una pieza nueva.
